[杭电OJ2005原题](https://acm.hdu.edu.cn/showproblem.php?pid=2005)
<!--more-->

题目就是给一个 YYYY/MM/DD 的日期，然后你需要计算当前日期是当年的第几天

```cpp
#include <iostream>
#include <string>
using namespace std;

int main(){
    int year, month, day;
    char ch;
    while(cin >> year >> ch >> month >> ch >> day){
        int sum = 0;
        for(int i = 1; i < month; i++){
            if(i == 2){
                sum += 28;
            }
            else if(i == 4 || i == 6 || i == 9 || i == 11){
                sum += 30;
            }
            else{
                sum += 31;
            }
        }
        sum += day;
        if(((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) && month > 2){
            sum++;
        }
        cout << sum << endl;
    }
    return 0;
}
```

这个需要注意的我认为是输入的读取，这里的分割符是 `/`，而 `std::cin` 默认是 `' '`(空格)
于是提供两种方式
1. 上述的用一个char去消费掉 `/`
cin对每种类型都有自己的解析规则：
    - int	遇到不能构成整数的字符
    - double	遇到不能构成浮点数的字符
    - char	读取一个字符
    - string	默认读到空白字符为止
2. 用 `std::getline`并指定读取的分隔符 `/`
```cpp
string s;
while(getline(cin, s)){
    stringstream ss(s);
    string token;
    while (getline(ss, token, '/')) {
        int x = stoi(token);
        cout << x << endl;
        // stoi(s);   // string -> int
        // stol(s);   // string -> long
        // stoll(s);  // string -> long long
        // stof(s);   // string -> float
        // stod(s);   // string -> double
    }
}

```
