[杭电OJ2073原题](https://acm.hdu.edu.cn/showproblem.php?pid=2073)
<!--more-->

题目就是在平面坐标轴第一象限，画折线，然后计算两个主对角线上的两个点之间的距离。

我的实现如下：

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

struct point{
    int x;
    int y;
};

double curve_dis(int mini, int maxi){
    double result = 0.0;
    while(mini<maxi){
        result += sqrt(mini*mini + (mini+1)*(mini+1));
        mini++;
        if(mini < maxi){
            result+= sqrt(mini*mini + mini*mini);
        }
    }
    return result;
}
int main(){
    int T;
    cin >> T;
    for(int i=0;i<T;i++){
        point a,b;
        cin >> a.x >> a.y >> b.x >> b.y;
        
        int A = a.x + a.y;
        int B = b.x + b.y;
        int mini = (A < B) ? A : B;
        int maxi = A + B - mini;
        double unit = sqrt(2);
        double result = curve_dis(mini, maxi);
        if(A < B){
            result += (a.y + b.x)* unit;
        }else if (A>B){
            result += (a.x + b.y) * unit;
        }else{
            result += abs(a.x - b.x) * unit;
        }
        cout << fixed << setprecision(3) << result << endl;

    }
    return 0;
}
```

从两种情况考虑：
1. 在同一主对角线
2. 在不同主对角线
主要观察：
1. 折线的单元长度都是 $\sqrt{2}$
2. 主对角线上的点的坐标之和是 +1 的递增数列，我成为该线的序号
3. 两个主对角线之间的 没有点的折线正好是其连接的两个主对线序号的平方和的算术平方根

因此：
1.同一主对角线知道它们的相对距离与unit即可算出折线距离
2.不同主对角线，知道它们的各自所在的主对角线序号以及横纵坐标关系就可计算折线距离
