[杭电OJ2002原题](https://acm.hdu.edu.cn/showproblem.php?pid=2002)
<!--more-->

题目很简单就是算球的体积，一个简单数学公式的实现

```cpp
#include <iostream>
#include <string>
#include <iomanip>
#include <cmath>
using namespace std;
#define PI 3.1415927
int main(){
    double r;
    
    while(cin >>r){
        double volume = (4.0/3.0)* PI *r*r*r;
        cout << setprecision(3) << fixed << volume << endl;

    }
    return 0;
}
```

这里其实没有用到 cmath，但是如果题目没有给 PI 的话，一般可以用 `PI=acos(-1)` 来得到
