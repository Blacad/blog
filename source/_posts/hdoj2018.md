[杭电OJ2018原题](https://acm.hdu.edu.cn/showproblem.php?pid=2018)
<!--more-->
本题是有一个母牛，每年初生一只小母牛，然后小牛过4年就可以再生小母牛，那么请问 n 年后有多少只母牛。
~~不是啊喂，为什么能保证生母牛的~~

我的解法：
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
  int n;
  while(cin >> n){
    if(n == 0) break;
     vector<int> v(1);
     v[0] = 4;
     for(int i = 1; i < n; i++){
        int curr_num = v.size();
        for(int j = 0; j < curr_num; j++){
            v[j]++;
            if(v[j]>=4){
                v.push_back(1);
            }
        }
     }
     cout << v.size() << endl;
  }
}
```
其实有点类似于 2009 类型的题目，都是通过递推来做的，或者更准确说是 **模拟** 即模拟指定过程的行为进而得到答案
我们知道 数列 往往有两种表现形式：
    1. 初始值 + 递推式
    2. 通项公式(直接计算某个index的值)
可见，通项公式往往能够更快得到某项的答案，而递推式却需要很久的计算，因此往往一般会想 通项公式

但是，有时候不想想了，或者压根没有通项公式的时候，就可以尝试用 递推 公式的方式去解决，或者说 **递推的思维**

像 2009 是很明显的递推形式，题目直接告诉你，下一项是前一项的平方根
而像 本题 你不能依据前一项或者前几项的形式告诉你本项是多少(项以年来看)，它需要你依据 之前所有项或某些特殊项的 **隐信息** 来推导 该项的值
这个 **隐信息** 的概念是我杜撰自 隐马尔可夫链 得来的，表象上来看(单视角)，之前项的信息就是之前的母牛数量，而仅仅知道之前的母牛数量无法推导之后的母牛数量，因此我们就需要探究之前项的 **隐信息**

基于此，我们就需要保存整个系统状态，以记录之前的隐信息而不是保留 结果本身，因此我们采用了 `vector` 保留系统状态
那么状态是什么呢？状态就是将题目中的对象抽象成只对解题有用的成分，比如本题中，对于母牛来讲只有它的年份是有用的因此母牛就抽象成了 `int`, 而 state 就由所有 `int` + `current_year` 组成

总结来讲，所谓 **模拟** 就是 将题目对象**抽象成state** + **保留全局state(隐信息)** 的递推过程，或者可以说是 **state的递推过程** 结果只是 state 信息的一部分
